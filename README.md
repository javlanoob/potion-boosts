# Potion Boost
Draws the skill icons a potion in your inventory would boost over the potion itself, each with how much it would add, or the level it would take you to.

- The numbers come from the game's own item data, so mixes, divines and brews are read the same way as the plain potions are, and a potion is shown as a boost when it would put a skill over the level you have it trained to. Food, restores and anything else that only puts back what has been used is left alone.
- A row disappears once you are already boosted as far as that potion goes, since there is nothing left in it to gain, and comes back as the boost wears off.
- Carrying several of the same potion labels one of them: the one with the least left in it, which is the one worth drinking first, or the one nearest the top left of your inventory. Different potions are labelled separately, so a super combat and a ranging potion both get their own.
